# 评测结果

> dev 集 123 个唯一 case，单次运行。真实模型与基线在同一套数据（仓库自带演示库投影）上测量。

## 1. 测的是什么

- **数据集**：`eval/datasets/r5/`，dev 123 个唯一语义 case（111 family、51 多意图、18 澄清），项目自建合成样本。
- **被测对象**：自然语言 → Router/Planner 生成结构化计划 → 运行时按能力参数契约归一化 → 经 A2A 运行时真实调用领域工具 → 检查终态与业务结果。
- **口径**：任务完成率 = 到达期望终态（回答 / 澄清 / 拒绝 / 待确认 / 人工）且必需读取成功、无未请求写。**不检查最终回答文字，也不代表写操作已提交**（写操作停在"等待用户确认"）。
- **分母**：123 例中 117 例可评估；6 例"数据冲突→问用户"因缺少冲突世界夹具被排除并记录。必需读取成功率分母 94；不必要澄清率分母 105。

## 2. 结果

模型：`deepseek-v4.1-flash`（输出预算 8000 token，尝试上限 2，temperature=0）。

| 指标 | 本系统 | 关键词基线 | oracle 上界 |
|---|---:|---:|---:|
| 意图 Core Macro-F1（11 类） | **0.853** | 0.463 | 1.000 |
| 意图 12 类兼容 Macro-F1 | 0.782 | 0.463 | 1.000 |
| exact handoff | **0.764** | 0.350 | — |
| 计划必需目标覆盖 | **0.780** | 0.480 | 1.000 |
| 计划符合性 | **0.772** | 0.309 | 1.000 |
| 必需读取成功 | **0.777** | 0.446 | 0.970 |
| 真实任务完成率 | **0.769**（90/117；全量 90/123 = 0.732） | 0.479（全量 0.463） | 1.000 |
| 不必要澄清率（越低越好） | **0.057** | 0.390 | 0.000 |
| schema 有效率 | 1.000 | 1.000 | 1.000 |
| 延迟 p50 | ~4.2 s | — | — |

说明：

- **Core 11 类**排除了 `MULTI_INTENT` 标签；该标签在 dev 中被编码为多个语义标签，gold support 为 0，纳入宏平均会失真。两项数值同时给出，避免混用。
- **oracle** 用 gold 构造计划，只用于验证指标可计算（能达到 1.0），不是系统能力结果。`exact handoff` 要求能力集合与必需集合完全相等，而 oracle 计划可能含合法可选能力，因此该项不作为其有效上界。
- 相对关键词基线：意图 Core Macro-F1 提升约 **+0.39**，真实任务完成率提升约 **+0.29**。

## 3. 失败分析（27 / 117 个可评估 case）

| 类型 | 数量 | 性质 |
|---|---:|---|
| 回答未达成 | 16 | 模型判断问题：选错能力、计划未覆盖必需目标 |
| 未到"待确认" | 8 | 售后动作只做了资格/读取，未计划写节点 |
| 该澄清未澄清 | 3 | — |
| 未请求写被拒绝 | 1 | 纯读请求多计划了写节点，被运行时拒绝（拒绝是正确行为） |

其中 26 例错误发生在模型决策层，而非运行时/工具层。

## 5. 如何运行

见 [`quickstart.md`](quickstart.md)。无 Key 的确定性路径不加载 `.env`、不联网：

```bash
pip install -r requirements-dev.txt
python scripts/r5_seed_synthetic_data.py --output-dir .tmp/r5-synthetic
python -m eval.r5_router_planner_eval --split dev --candidate keyword_router --data-dir .tmp/r5-synthetic
python -m eval.r5_router_planner_eval --split dev --candidate oracle        --data-dir .tmp/r5-synthetic
python -m pytest -q
```

## 6. 限制

- 数据为项目自建合成样本，非外部客户流量；来源分层（订单为本地只读投影、物流为订单派生快照、商品/售后自建、政策为确定性夹具）。
- 写操作停在待确认；"确认后提交完成"未测量。
- 未实现 replan，不主张动态规划增益。
- 任务完成率不含最终回答文案质量。
- 指标存在跑间波动（temperature=0 下 macro-F1 约 ±0.03–0.05），对外建议报区间或保守值。
- 绝对门槛尚未全部达到（handoff、计划覆盖/符合性、必需读取、任务完成率低于 0.90/0.85 目标）；本结果用于说明系统当前能力，不宣称生产可用或外部泛化。
